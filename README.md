# Equilibrio

App web instalable sencilla para registrar peso, comidas y actividad. Los datos se guardan en el almacenamiento local del navegador.

## Publicar con GitHub Pages

1. Sube este proyecto a un repositorio de GitHub y usa `main` como rama principal.
2. En **Settings → Pages**, selecciona **GitHub Actions** como fuente de publicación.
3. El workflow `.github/workflows/pages.yml` publicará el sitio en una URL HTTPS de GitHub Pages cada vez que actualices `main`.
4. Abre esa URL en Safari en el iPhone y usa **Compartir → Añadir a pantalla de inicio**.

No ingreses información sensible: esta versión guarda registros solo en el navegador del dispositivo y no los cifra ni sincroniza.
